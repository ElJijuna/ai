Chrome (Prompt API enabled) uses Gemini Nano directly. Other WebGPU-capable browsers (Safari, Firefox) fall back to an on-device open model via @mlc-ai/web-llm -- run npm install @mlc-ai/web-llm first, then serve this page with npm run demo (a plain file:// open won't resolve the import map below).
